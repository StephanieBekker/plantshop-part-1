# CartApplikation

En responsiv plantebutik bygget med React og Redux Toolkit.

## Funktioner

- Tilføj produkter til kurven
- Ændr antal med plus, minus eller inputfeltet
- Fjern et produkt fra kurven
- Tøm hele kurven
- Se produktpris og samlet pris

## Kør projektet lokalt

```bash
npm install
npm run dev
```

Projektet er lavet som en skoleopgave med fokus på React-komponenter, props og Redux state.
